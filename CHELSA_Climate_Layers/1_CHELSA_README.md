# CHELSA DATA

## Why script, no raster? 

Raster files were large, and couldn't be uploaded. Instead, this script can be used to upload the rasters and process them in the same way they were for the Alpine models. 

Hindcast URL is a list of URLs similar to the base URL found in the current and future climate rasters, but there are many more for all the 221 years and 20 environmental variables. The script runs through each line in the .txt file and downloads them.
