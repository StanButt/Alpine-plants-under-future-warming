# GBIF Occurence data
### All Occurence records were downloaded from GBIF, available here https://doi.org/10.15468/dl.3dgbn7

GBIF query criteria included
 - Has Coordinates: YES
 - Has Geospatial Issues: NO
 - Occurence Status: PRESENT
 - Scientific Name: Arabis alpina
   
Original data included 40,459 records composed of records from 337 datasets; 154 publishers, 34 publishing countries.
